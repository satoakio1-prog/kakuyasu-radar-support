KAKUYASU BUKKEN RADAR

格安物件レーダー

アプリの使い方・注意事項・お問い合わせ

現在は宮崎県で実証中です

対応バージョンでは、国土交通省 Project LINKSの許諾済みオープンデータから宮崎県の候補を取得し、物件ランキング、最初の指値、絶対上限、総投下額、賃貸純利回り、売却利益、危険判定を確認できます。現在のデータ基準日は2025年3月31日です。

基本的な使い方

  1. 候補画面の「更新」を押し、宮崎県の公開データ候補を取得します。
  2. ランキングで純利回り、指値、絶対上限、値下げを比較します。
  3. 右端の「出典」から国土交通省のデータセットを確認します。
  4. 物件を開き、公開データの事実、独自試算、危険・保留項目を確認します。
  5. 現地内覧と修繕見積を行い、総投下額を更新します。
  6. 絶対上限を超えない範囲で交渉案・入札案を検討します。

大切な注意

  • 表示する価格・利回り・修繕費・利益は参考試算で、収益や購入結果を保証しません。
  • 購入、入札、契約、送信をアプリが自動で確定することはありません。
  • 公開データは2025年3月31日時点です。購入前に自治体、不動産会社、宅地建物取引士、司法書士、建築士などへ掲載継続と最新情報をご確認ください。
  • 個別物件の説明文や写真を販売するものではなく、許諾済み公開データの事実、出典、独自の計算・判定を提供します。

公開データの出典

物件番号、市町村、価格、築年、構造、面積、間取り、駐車場は、国土交通省 Project LINKS「空き家・空き地バンク登録物件データ（2025年度）」に基づきます。株式会社LIFULLが提供した情報を国土交通省がオープンデータ化したものです。
